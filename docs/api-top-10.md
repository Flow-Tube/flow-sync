# OWASP API Security Top 10 (2023)

This maps the server, the deployment templates in `deploy/` and the CI workflows to the [OWASP API Security Top 10 2023](https://owasp.org/API-Security/editions/2023/en/0x11-t10/). The apps are out of scope here. The ASVS mapping, which cites the same code in more detail, is in [asvs.md](asvs.md).

Status is `met`, `partly`, `gap` or `n/a`. Paths are relative to `packages/server/src/` unless they start with `spec/`, `deploy/`, `docs/` or `.github/`. Tests are named as `file` "test name".

| Id | Requirement (short) | Status | Where / why |
|---|---|---|---|
| API1:2023 | Broken Object Level Authorization | met | A member reads only its own wrap (`routes/keys.ts:14`), writes only under its own id (`routes/objects.ts:70`) and deletes only its own or removed devices' paths (`routes/objects.ts:103`); every member reads the group's ciphertext by design. `routes/keys.test.ts` "a member reads its own wrap and the chain, nothing else", `routes/objects.test.ts` "a device can't write as another device, and the recovery key can't write", "a device deletes its own objects and those of removed devices" |
| API2:2023 | Broken Authentication | partly | Single-use 60-second challenges signed with Ed25519 (`routes/auth.ts:45-61`), 15-minute HMAC tokens checked against the roster on every request (`auth/device.ts:26-36`), constant-time admin check (`auth/admin.ts:16`), failure bans (`limits/guards.ts:45-53`); `routes/auth.test.ts` "a challenge works once, for its device, before it expires", "tokens expire and can't be altered". Partly: the admin token is a static secret, and bans per address lock out everyone behind that address (ASVS V6.1.1, V7.2.2) |
| API3:2023 | Broken Object Property Level Authorization | met | Strict request schemas reject unknown fields (`z.strictObject`, e.g. `routes/auth.ts:13-18`); responses list fixed fields (`routes/status.ts:13-15`, `routes/admin.ts:28-34`, `routes/objects.ts:114-117`) |
| API4:2023 | Unrestricted Resource Consumption | partly | Body, object, page, mailbox and live limits (`limits.ts`), read timeouts (`runtime/node.ts:41`), quota (`routes/objects.ts:79`), per-address and per-device rates (`limits/guards.ts`), bounded in-memory counters (`limits/counters.ts:2-8`). Partly: the per-address limit doesn't cover every request to routes that need no token (`limits/guards.ts:49`), the quota check isn't atomic (`routes/objects.ts:79-86`), and on Workers limits are per isolate (`docs/cloudflare.md`) |
| API5:2023 | Broken Function Level Authorization | met | `requireAdmin` on claim, join requests and `/v1/admin/*` (`routes/claim.ts:19`, `routes/join.ts:35`, `routes/admin.ts:21`), `requireMember` elsewhere, and the recovery member only on roster and keys (`auth/device.ts:32`); `routes/auth.test.ts` "the recovery member authenticates but can't use device routes", `routes/join.test.ts` "asking needs the admin token, answering needs a member", `routes/admin.test.ts` "admin routes are closed when admin access is off" |
| API6:2023 | Unrestricted Access to Sensitive Business Flows | met | Claim works once (`routes/claim.ts:22`); members open at most 3 pairing slots of 180 s (`routes/pair.ts:31-38`); join requests need the admin token, at most 3 pending (`routes/join.ts:35-43`); `routes/pair.test.ts` "slots expire, can be closed, and only a few are open at once", `routes/join.test.ts` "requests are bounded and a member can decline one" |
| API7:2023 | Server Side Request Forgery | n/a | No request data chooses an outbound destination; the server talks only to the operator's database and bucket (`storage/from-env.ts:10-21`) |
| API8:2023 | Security Misconfiguration | partly | Distroless non-root image (`deploy/docker/Dockerfile:16-20`), read-only root, dropped capabilities and `no-new-privileges` (`deploy/docker/compose.yaml:15-21`), security headers and `no-store` (`app.ts:36-46`), no CORS, generic errors (`http/errors.ts:42-49`). Partly: HSTS lasts 180 days and CSP lacks `frame-ancestors` and `base-uri` (ASVS V3.4.1, V3.4.3, V3.4.6); Caddy and Fly redirect HTTP (V4.1.2); the Railway guide runs the container as root (`docs/railway.md:9`); the Heroku guide skips Postgres certificate checks (`docs/heroku.md:12`); Compose pulls `:latest` (`deploy/docker/compose.yaml:7`) |
| API9:2023 | Improper Inventory Management | met | One API version, `/v1`; every route is in `spec/api.md` Endpoints and mounted in `app.ts:58-71`; `/v1/info` reports versions and limits (`routes/meta.ts:12-20`); `docs/README.md` lists every host template and what was verified on each |
| API10:2023 | Unsafe Consumption of APIs | met | The store is untrusted (`spec/threat-model.md` A2): roster entries read back from it are re-validated with their signatures (`group.ts:113-128`), and stored bytes are served only as opaque attachments (`http/body.ts:44-48`) |
